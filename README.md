# Мебель на заказ — Ижевск

**Неофициальный демонстрационный сайт** для компании из сообщества VK [`club49220614`](https://vk.com/club49220614). Не является действующим официальным представительством компании, не получает заявки и не принимает оплату.

## Как посмотреть

1. Откройте файл `preview-offline.html` в обычном браузере. Он полностью автономный: иллюстрации, стили и скрипты встроены в один HTML-файл.
2. Или откройте `index.html`: для него рядом нужны папка `assets`, `styles.css` и `script.js`.

## Размещение на Vercel

1. Распакуйте архив и загрузите содержимое папки `Mebel_Izhevsk_Website_Vercel` в корень отдельного репозитория GitHub.
2. В Vercel создайте **New Project**, импортируйте репозиторий и установите **Framework Preset: Other**.
3. **Build Command:** не нужен. **Output Directory:** пусто. Нажмите **Deploy**.
4. Vercel опубликует `index.html`. Адрес домена выбирается внутри Vercel.

Это статический сайт на HTML/CSS/JavaScript. Устанавливать Node.js, npm или зависимости не требуется.

- Изображения в `assets/` — **авторские иллюстрации**, а не фотографии готовых работ компании.
- Портфолио реальных выполненных заказов, цены, точные сроки, независимые отзывы, адрес производства, ФИО владельца, конкретные материалы и фурнитура **не установлены**. Такие сведения намеренно не выдуманы.
- Названия направлений и упоминания замера, договора и гарантии основаны на описании сообщества VK; наличие, сроки, условия и доступность требуют согласования с владельцем перед переходом в официальный режим.
- Загруженные в конструктор изображения остаются только на устройстве пользователя; никакие данные на сервер не отправляются.
- Файлы `robots.txt`, `vercel.json` и мета-тег `noindex` настроены на запрет индексации до разрешения владельца.
